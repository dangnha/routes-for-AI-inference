# Example images

These images are generated by `scripts/make_samples.py` (license-free, no
third-party assets). They exist so each model has an input it is actually good
at — the frontend offers them as one-click examples instead of making users
hunt for a suitable image.

| Folder | Best for model | Contents |
| --- | --- | --- |
| `printed/` | `trocr` | Single-line printed text (a sentence, a headline). |
| `multiline/` | `easyocr` | Multiple lines: a receipt, a street sign, an address label. |
| `document/` | `gotocr` | Full pages with headings, paragraphs and tables. |

Regenerate with:

```bash
python scripts/make_samples.py
```
